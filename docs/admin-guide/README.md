## 2026-10-01 更新記錄

- 正式站：`https://nnkieh-novae.vercel.app`。本機核對起點：`8d2d1bf4`；這不是對正式站部署版本的聲明。
- 修正舊導覽為首頁／列表／通知／設定，補新版列表、抽屜、格式工具、草稿及圖片政策位置。
- 區分列表徽章和管理表單的狀態用字，保留七種提案狀態及四種設備狀態；不把審核退件與附議未達標混用。
- 學生權益與公告留言支援附件，不再寫只能輸入文字。現行介面只在自己的留言旁顯示刪除圖示，不把後端權限寫成已存在的介面入口。
- 公共議題的使用及管理步驟持續不介紹留言；詳情截圖裁掉對話區域。
- 保存並上傳 45 張實際截圖。列表作者以不透明色塊遮蔽，詳情關閉作者顯示，帳號與負責人的姓名、頭像、信箱、UID 一併遮蔽。
- 提案示例只填未送出草稿，最後核對標題與內容都為空；新增分類示例已捨棄。沒有新增正式案件、公告或分類，也沒有送出既有案件的管理狀態變更。
- 設備仍關閉，手冊將設備操作標為啟用前預備說明。
- 發現正式站從公告列表進新增頁可能被開成載入失敗的公告詳情；在新增網址重新整理可開啟表單，已寫入總管理員手冊。此次更新未修改應用程式。
- 三頁更新後重新 fetch：圖片引用都已解析、使用教學仍保留兩個原管理員子頁。Chrome 亦確認新版內容與已上傳圖片可顯示。

## 日後更新

1. 先讀三份原頁面與正式站設定，特別核對學校啟用範圍、附議規則及圖片上限。
2. 按 `AGENTS.md` 用受控瀏覽器取得截圖位元組，保存絕對路徑。圖片裁切前查尺寸和邊界；覆寫前先取得 buffer。Windows 若圖片處理套件持有來源檔，先讀來源 bytes 再處理。
3. 個資用不透明色塊遮蔽，逐張開圖檢查。公共議題截圖不要包含對話教學。示例優先使用草稿，完成後捨棄或清空。
4. 新截圖放日期子目錄，不把原始個資圖、上傳 token、短效 signed URL 或臨時檢查圖提交到 Git。
5. 對 Notion 進行完整換版時，保留使用教學內兩個原生子頁 `<page>` 區塊；一般跨頁參照用 `<mention-page>`。表格轉成 Notion 原生表格，圖片用同一整合上傳後的引用。
6. 更新後重新讀頁核對正文、圖片數與子頁關係，再到目標頁看圖片顯示。同步修改本機 Markdown，分批 commit。

本機 Markdown 的圖片使用相對路徑，Notion 頁面使用已上傳圖片。兩邊文字要一起維護；不要直接把帶短效圖片網址的 fetch 結果當成長期來源。
